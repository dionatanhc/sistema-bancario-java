# 🏦 Sistema de Conta Bancária

## 📖 Descrição do Sistema
Este projeto consiste em um sistema simples de conta bancária desenvolvido com o objetivo de simular operações básicas realizadas por um banco. O sistema permite a criação de contas, bem como a execução de operações como depósito, saque e consulta de saldo.

A aplicação foi construída com foco em reforçar conceitos fundamentais de programação, como orientação a objetos, organização de código e separação de responsabilidades.

---

## 💻 Tecnologias Utilizadas
- Java
- Programação Orientada a Objetos (POO)

---

## ⚙️ Funcionalidades
- ✅ Criação de conta bancária
- 💰 Depósito de valores
- 💸 Saque de valores (com validação de saldo)
- 📊 Consulta de saldo
- 🔒 Validações básicas para evitar operações inválidas

---

## 🧠 O que eu aprendi
Durante o desenvolvimento deste projeto, pude praticar e reforçar os seguintes conceitos:

- Estruturação de um projeto do zero
- Aplicação de conceitos de Programação Orientada a Objetos (classes, atributos e métodos)
- Separação entre lógica de negócio e interação com o usuário
- Boas práticas de organização de código
- Lógica para validação de regras de negócio (como saldo insuficiente)
